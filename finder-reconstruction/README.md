# WYRPLAY Find Questions

独立的 Next.js 静态前端，只实现 `finder.png` 对应的找题库首页。所有题目与样本票数写在前端，无账号服务、投票接口或外部 API。没有修改主项目、其他独立原型或部署配置。

## 运行

```sh
cd /Users/milushangdi/Projects/wyrplay/finder-reconstruction
bun install
bun run dev
```

打开 http://127.0.0.1:4191/ 。当前工作区可直接复用父目录已安装的依赖。

`bun run build` 输出静态网站到 `out/`，可以部署到普通静态托管服务。`bun run verify` 运行类型检查、ESLint 和生产构建。开发服务开启时运行 `bun run verify:browser -- round-05` 可检查交互；重新采集时需先使用 draw-ui 的 `prepare_capture.py` 创建新的轮次目录，避免覆盖历史。

## 范围与交互

- 首页完整覆盖导航、Hero、搜索、热门搜索、5 类筛选、10 张题目卡片、分页外观、选题栏和底部分类入口。
- 搜索与空结果、暂存筛选/应用/清空、收藏开关、选择/取消、逐题播放、本地选择、演示模式、打印筛选或选中的题目均可操作。
- 示例只提供截图内的 10 道题。其他分页、账号和排行榜入口会明确提示原型边界；分类入口滚动至筛选区域。收藏和选择仅保存在当前页面内存，刷新后重置。
- 筛选采取任一已选标签匹配；没有对应示例数据的标签返回空结果，不补造题目。票数和比例沿用设计稿，播放后的个人选择不会伪造服务器投票。

## 视觉基线与素材

原图 849 × 1852，校准逻辑视口 849 × 900、DPR 1，采集完整长页。桌面页面最大宽度 849px；390/700px 为响应式扩展，1024px 显示居中的桌面版。

布局、标题、文字、控件、普通 SVG 图标均为可编辑代码。角色、Logo、卡片插画、少量独特图标和装饰使用原图独立裁切；对邻近正文残片做逐项遮罩，并移除边缘连通的浅色背景。裁图原始坐标与后处理记录在 `evidence/assets.json`。没有把整页截图作为页面背景，也没有重新生成品牌或伪造高清细节。

本轮没有调用 image 2.5：素材按原图有效尺寸使用，没有需要超出原生分辨率的局部放大。若之后要求大幅放大或 DPR 2 插画精度，需要高清原稿或进一步重绘；不能把插值放大称为高清恢复。

字体为本地 Chewy、Roboto、Roboto Condensed；这些是按字形对照选择的近似字体，无法从栅格设计稿确认原始字体。字体来自 Google Fonts，字体授权见 `public/fonts/licenses/`。早期轮次的 Lilita One/Kalam 字体未用于最终页面。
