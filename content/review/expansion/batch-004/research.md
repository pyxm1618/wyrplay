## Core Dilemma Index

Before producing Batch 004, all 236 formal questions were read and treated as semantic anchors. The working index did not rely only on surface nouns. Each formal item was interpreted in terms of:

- the actual choice axis;
- the cost or benefit on each side;
- the user/audience relationship;
- whether the setting is intrinsic to the dilemma;
- the mechanism of the choice: information, resource, sensory, role, timing, collaboration, movement, discovery, etc.

The following axes were identified as particularly saturated and therefore heavily restricted in Batch 004:

- planning vs spontaneity;
- together vs separate;
- vote/group decision vs one chooser;
- one large experience vs several smaller experiences;
- fixed vs flexible schedule;
- familiar vs new;
- lead vs follow;
- start vs finish;
- learn skill A vs learn skill B;
- broad variety vs deep specialization;
- ask for help vs keep trying alone;
- solo practice vs social practice;
- surprise date vs planned date;
- music control vs game control;
- movie activity vs game activity;
- basic aesthetic preference with no meaningful consequence.

The Foundation Batch 002 and Expansion Batch 003 review/re-review files were also read. Historical `REJECT`, `duplicateGroups`, and Reviewer explanations were treated as a negative semantic index, not merely as old records.

## New Dilemma Families Learned

Batch 004 deliberately expanded the internal production vocabulary. The most useful underrepresented structures learned or reinforced through research were:

### Information asymmetry
Different players know different things, or one side has complete information of one kind but incomplete information of another kind.

Examples of structures:
- goal known vs time limit known;
- examples vs success criteria;
- map structure vs verbal directions;
- taste feedback vs timing feedback.

### Sensory channel trade-offs
The choice is not merely “sound thing vs visual thing”; the information or experience itself changes depending on sight, sound, smell, touch, texture or rhythm.

### Resource constraints
The user chooses between different scarce capabilities:
- specialized tool vs improvised available tools;
- access vs ownership;
- retry token vs information advantage;
- storage capacity vs another convenience.

### Representation modes
The same idea can be communicated or remembered through:
- objects;
- movement;
- audio;
- drawings;
- symbols;
- written language;
- physical artifacts.

### Movement and motor-control constraints
Especially useful for ages 4–9:
- carrying vs balancing;
- pushing vs pulling;
- large-body movement vs fine control;
- direction restrictions vs timing dependencies.

### Problem-solving mechanism
Different methods solve the same concrete objective:
- prevention vs repair;
- diagnose failure vs infer purpose;
- improve an existing attempt vs start from first principles;
- slope vs enclosure;
- filter irrelevant information vs infer missing information.

### Role asymmetry
Two roles are both useful but provide different access or responsibility. This is different from the saturated “leader vs follower” axis.

### Discovery mechanism
A choice can differ by *how* something is found:
- observation vs deduction;
- clues from people vs environment;
- membership examples vs non-examples;
- text evidence vs visual evidence.

### Memory medium
Physical artifact, sound, writing, image, ritual and inside language preserve different aspects of the same experience.

### Competition mechanism
Instead of generic “win by skill vs luck,” Batch 004 explored:
- consistency vs peak performance;
- defensive protection vs opportunistic copying;
- comeback mechanics;
- accuracy vs creativity;
- prosocial bonus vs self-imposed challenge.

### Comfort trade-offs
Comfort can be decomposed into:
- space;
- acoustics;
- glare;
- view;
- access;
- seating;
- waiting;
- environmental conditions.

### Creative constraint
Creativity questions improve when the constraint meaningfully changes the process:
- subtraction vs impossible addition;
- fixed materials;
- forbidden words;
- output medium;
- prompt type;
- change triggered by use.

These families are internal production tools, not front-end taxonomy.

## Collections that were hardest to expand

### Kids 4–6
The difficult constraint was keeping language and imagery concrete while still creating a true consequence-based choice. Cute-object substitution was repeatedly rejected during drafting.

### Friends
The formal bank already contains many planning, together-vs-separate and group-choice structures. New Friends questions required moving toward game mechanics, communication constraints, memory, creativity and asymmetric information.

### Couples / Date Night
Planning, shared-vs-separate activities, familiar-vs-new outings and scheduling are already crowded. Batch 004 therefore shifted toward sensory experiences, culture, food mechanics, artifacts, communication and playful hypotheticals.

### Icebreakers
The main risk is producing meta-prompts (“which question would you rather answer?”) or shallow preference questions. The retained set uses substantive but low-disclosure choices.

### Coworkers
The challenge was avoiding another office-process questionnaire. Retained questions include creative constraints, information structures, mock puzzles, prototypes, communication channels and workplace-safe imaginative mechanics.
