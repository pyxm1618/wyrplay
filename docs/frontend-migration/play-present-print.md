## 接入位置与行为

- /play：独立答题页；现有 DuelArena 新增 illustrated-play 展示分支，保留原 GET/POST 投票接口与旧展示分支。首页、分类页及榜单原来的嵌入答题区保持兼容。
- PresenterModal：现有投屏组件替换为设计稿的浅色双色布局，找题库、答题页、首页和分类页复用。保留上下题边界、键盘翻题、Esc、焦点恢复；投屏翻题不会触发后台答题投票。
- /print：同页切换 Cut-out Cards 与 Question Sheet，接通 Letter/A4、裁切线/答题圈、缩放、预览翻页、实际打印与真实 PDF 下载。选择态始终与预览格式一致。
- 找题库入口携带真实题目 ID 组成的题集；返回时恢复提交的搜索、筛选草稿/生效值、分页和跨页选择。收藏共用本机存储；分享链接包含当前真实 question ID。未知 ID 不产生替代题目。
- 正式题库没有选项解释字段，不编造设计稿中的解释。人数、统计、题数、页数、标签和登录入口服从真实数据与原有功能开关。
