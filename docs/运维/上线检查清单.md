# WYRPlay 上线检查清单

本文件是当前发布检查入口，并由 release gate 要求存在。

## 代码与 CI

- [ ] PR 基于最新 `main`，无未解释的基线漂移。
- [ ] format / lint / typecheck 通过。
- [ ] unit / integration / contract 通过。
- [ ] migration verification 通过。
- [ ] SEO / i18n / security / release verification 通过。
- [ ] browser E2E、performance、clean-setup 通过。
- [ ] Cloudflare production build 通过。
- [ ] Hyperdrive platform proxy verification 通过。

## 产品数据

- [ ] `content/question-bank/questions.json` 是唯一正式题库。
- [ ] question-contract tests 与题库数量、审核状态一致。
- [ ] 不存在重复 ID。
- [ ] 未审核/退役/拒绝内容没有被正常可玩池放行。
- [ ] 没有用 mock vote / fake percentage 替代真实生产统计。

## Kids

- [ ] Kids collection 的内容年龄和 safety 标记符合当前审核结论。
- [ ] Kids voting 不创建或读取持久化 voter cookie。
- [ ] Kids vote 没有引入可复用的儿童/浏览器识别符。
- [ ] Analytics / advertising 行为符合当前 Kids 隐私设计。

## SEO

- [ ] production mode canonical 指向 `https://www.wyrplay.com`。
- [ ] indexable route 的 title / description / H1 / sitemap 状态与 route registry 一致。
- [ ] noindex/private/system route 没有被错误收录。
- [ ] 新筛选条件没有意外生成可抓取参数组合页。

## Cloudflare

- [ ] `wrangler.jsonc` 的 production origin 正确。
- [ ] Hyperdrive、R2 incremental cache、Images binding 指向批准资源。
- [ ] production deploy 使用当前 `main` SHA。
- [ ] secret 仅在批准的 secret store / environment 中配置。
- [ ] readiness / health 不泄露连接细节。

## Analytics

- [ ] GA4 / Clarity 仅在同意边界允许后加载。
- [ ] 撤回同意后停止后续 analytics 事件。
- [ ] 自定义事件不包含 email、题目自由文本或其它不必要个人数据。

## Dormant capabilities

Production auth、email、commerce、subscriptions、credits 当前关闭。

- [ ] 若本次没有明确启用，确认仍保持关闭。
- [ ] 若计划启用，另走对应专项验收，不把 dormant code 的存在当作生产 readiness。

Commerce 激活必须先满足 `docs/参考/waffo-合约与验收.md`。

## 发布后

- [ ] 生产首页和主要交互可访问。
- [ ] vote read/write 与显示结果一致。
- [ ] Kids vote 路径按隐私预期工作。
- [ ] sitemap / robots / canonical 正常。
- [ ] 监控无新增高优错误。
