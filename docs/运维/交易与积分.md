# WYRPlay 交易与积分

## 当前状态

Production commerce、one-time payments、subscriptions 和 credits 当前全部关闭。

这份文档仍存在，是因为平台保留了相关安全代码、测试和未来激活能力，同时 release gate 要求固定路径存在。它不是“生产已经收费”的证明。

## 禁止事项

在 production feature flag 关闭时：

- 不暴露可完成真实收费的 checkout；
- 不创建无意义的 commerce cron；
- 不把测试商户当生产资源；
- 不把本地/测试 webhook 成功当成真实商户验收；
- 不为通过配置而伪造 product/payment/subscription 状态。

## 未来启用条件

启用 commerce 前必须独立完成：

1. 产品和价格最终确认；
2. 法律文本与退款/取消规则确认；
3. Waffo 真实商户、店铺、商品/价格、webhook、查询契约验收；
4. production secrets；
5. durable job scheduling；
6. webhook signature / idempotency / reconciliation；
7. refund / subscription state machine 验证；
8. production-mode browser flow；
9. rollback and incident runbook。

Waffo 的强制门禁见 `docs/参考/waffo-合约与验收.md`。

## 安全不变量

Dormant code 也必须继续满足：

- browser input 不决定价格或支付成功状态；
- checkout return page 不授予 entitlement；
- webhook / provider facts 必须做本地幂等；
- uncertain external state 进入 reconciliation，而不是直接强改成功；
- refund 总额不能超过 captured amount；
- credit grant / reserve / commit / release / reversal 保持可审计与幂等。

这些不变量由代码和测试执行，本文不复制实现细节。
