# WYRPlay 题库数据契约规范

版本：1.1.0
生效日期：2026-09-30
适用对象：代码工程开发、题库负责人、题库编辑与审核流程

> **产品定位与概念明确**：
> WYRPlay **不是** AI 产品。产品运行时不调用任何大模型、不需要 AI API、不自动生成题目、不做 AI 推荐、不做 AI 审核。所有正式题库内容均由题库负责人及人工审核流程把关。

---

## 1. 契约背景与目标

本契约是 WYRPlay 产品代码与题库内容之间的共享数据标准。
- 代码工程依据本契约进行类型定义、合法性校验、维度筛选、搜索匹配、投票关联和渲染；
- 题库编辑/审核流程依据本契约对现有题目进行逐题人工审校、标注维度、补充新题及决定发布状态；
- 两端必须严格遵守字段定义与语义边界，代码端严禁通过猜测或模糊映射代替人工审校结论；
- **未审核题目严禁进入正式可玩集合**：只有 `reviewStatus === "approved"` 的题目方可进入 Arena、Random 及真实投票。未审核题目在题库中保持空语义数组与 unreviewed 状态。

## 2. 核心数据结构 (TypeScript 规范)

```typescript
/** 建议年龄段标识 */
export type AgeGroup = "4-6" | "7-9" | "10-12" | "13-17" | "18+";

/** 参与关系标识 */
export type Relationship = "friends" | "family" | "couples" | "coworkers";

/** 使用场景标识 */
export type Occasion = "classroom" | "party" | "road-trip" | "dinner" | "date-night";

/** 气氛基调标识 */
export type Tone = "funny" | "weird" | "deep";

/** 难度等级标识 (仅限有人工审核依据时标定，未审核状态下不设值) */
export type Difficulty = "easy" | "hard";

/** 8大标准话题标识 */
export type Topic =
  | "animals-nature"
  | "food-everyday"
  | "fantasy-superpowers"
  | "school-learning"
  | "travel-adventure"
  | "hobbies-entertainment"
  | "relationships-values"
  | "work-money";

/** 适用性审核判定 */
export type SuitabilityRating = "suitable" | "unsuitable" | "unreviewed";

/** 适用性审核维度集合 */
export interface ContentSuitability {
  readonly kids: SuitabilityRating;       // 儿童适用性 (安全健康、无成人/惊悚)
  readonly family: SuitabilityRating;     // 混龄家庭共同参与 (老少咸宜)
  readonly classroom: SuitabilityRating;  // 课堂公开发言适宜 (不涉隐私泄露、无霸凌嫌疑)
  readonly workplace: SuitabilityRating;  // 职场破冰适宜 (符合职业社交边界)
}

/** 题目编辑审核状态 */
export type ReviewStatus = "unreviewed" | "approved" | "deferred" | "rejected";

/** 核心题目实体契约 */
export interface Question {
  /** 永久稳定唯一标识符 (例如: "wyr-001")，题意改变必须生成新 ID */
  readonly id: string;
  /** 题干，英文，清晰明确的 "Would you rather..." 问题 */
  readonly question: string;
  /** 选项 A，英文 */
  readonly optionA: string;
  /** 选项 B，英文 */
  readonly optionB: string;
  
  /** 建议年龄段 (允许多选) */
  readonly ageGroups: readonly AgeGroup[];
  /** 参与关系 (允许多选) */
  readonly relationships: readonly Relationship[];
  /** 使用场景 (允许多选) */
  readonly occasions: readonly Occasion[];
  /** 气氛基调 (允许多选) */
  readonly tones: readonly Tone[];
  /** 抉择难度 */
  readonly difficulty: Difficulty;
  /** 所属话题 (通常 1-2 个) */
  readonly topics: readonly Topic[];

  /** 内容适用性审核结论 */
  readonly suitability: ContentSuitability;
  /** 编辑审核状态 */
  readonly reviewStatus: ReviewStatus;
  
  /** 审核说明或历史修改备注 (可选) */
  readonly reviewNotes?: string;
}
```

## 3. 维度语义与约束规则

### 3.1 题目身份与投票继承
- **永久稳定 ID**：ID 是题目的全局唯一标识（例如 `wyr-001`）。
- **修改原则**：
  - 仅修复拼写错误、标点符号、微小错别字且**不改变题意**的修改，保留原 ID；
  - 任何改变题意、前提假设、选项权重或 A/B 实质内容的修改，必须赋予全新 ID；
  - **严禁**将旧题的历史投票迁移到修改后的新题上。
- **退役题**：不被采用或淘汰的题目，其 `reviewStatus` 设置为 `rejected` 或 `deferred`，不进入前端可玩题集，但数据库中已有的历史投票不被物理删除。

### 3.2 建议年龄 (`ageGroups`)
- `4-6`：幼儿与学前儿童，适合成人朗读、短句、熟悉具体物品；
- `7-9`：小学低年级，日常生活、学校、动物、简单幻想；
- `10-12`：高年级儿童，爱好、友谊、轻度社交与公平讨论；
- `13-17`：青少年 (Teens)，同伴交往、学校、生活独立性选择；
- `18+`：成人 (Adults)，成年人生活、工作、家庭、价值观选择（不代表 NSFW/恶俗）。
- **规则**：
  - Kids 专题对应 `4-6`、`7-9`、`10-12`；
  - Teens 对应 `13-17`；
  - Adults 对应 `18+`；
  - 严禁将旧版未经区分的 "kids" 标签直接批量自动填为 `["4-6", "7-9", "10-12"]`，必须由题库审核流程审定。

### 3.3 参与关系 (`relationships`)
- `friends`：朋友聚会、玩伴；
- `family`：多代家庭共同参与（必须考虑最小年龄与家庭氛围）；
- `couples`：伴侣/情侣约会探讨（不默认已婚或育儿）；
- `coworkers`：同事/团队破冰（不等于必须谈论工作本身，但需保证职场安全感）。

### 3.4 使用场景 (`occasions`)
- `classroom`：课堂早会、学生破冰（需适合全班公开作答）；
- `party`：聚会派对、游戏之夜；
- `road-trip`：公路旅行、车内口头交谈（易于口述、不需视觉辅助）；
- `dinner`：餐桌闲谈；
- `date-night`：约会之夜。

### 3.5 气氛与难度
- `tones`：
  - `funny`：幽默滑稽、引人发笑；
  - `weird`：离奇古怪、脑洞大开；
  - `deep`：深思熟虑、引发认真探讨。
- `difficulty`（可选，未审核时不强行指定）：
  - `easy`：两个选项都很有吸引力或取舍轻松明确；
  - `hard`：艰难抉择、左右为难。

### 3.6 8 大起始话题 (`topics`)
1. `animals-nature`（动物与自然）
2. `food-everyday`（美食与日常琐事）
3. `fantasy-superpowers`（超能力与幻想世界）
4. `school-learning`（校园与求知）
5. `travel-adventure`（旅行与冒险）
6. `hobbies-entertainment`（文娱、运动与爱好）
7. `relationships-values`（人际关系、情感与价值观）
8. `work-money`（职场、金钱与事业）

### 3.7 内容适用性审核 (`suitability`)
- `suitable`：经题库负责人/人工审校确认在该场景/人群完全合规安全；
- `unsuitable`：经确认不适合（例如含有少儿不宜隐喻则 `kids: "unsuitable"`）；
- `unreviewed`：未完成该维度的审核，**代码端绝不把未审核视为适用**。

## 4. 正式发布准入标准 (P0-2 铁律)

1. **公开可玩集合 (Arena / Random / Presenter / 投票)**：
   - **核心铁律**：只有 `reviewStatus === "approved"` 的题目才可被纳入可玩题集，并在 Arena、Random、Presenter 中游玩或接受真实投票；
   - 未审核 (`unreviewed`) 题目在题库中保持空语义数组，绝对不进入可玩集合与投票系统；
   - 暂缓 (`deferred`) 与 淘汰 (`rejected`)、退役 (`retired`) 题目严禁接受新投票；
   - 若当前题库没有 approved 题目，页面正常渲染并展示明确的“题库审核中 / 暂无可玩题目”状态，绝不为了填补页面而放宽条件，绝不伪造票数或塞入未审核题。
2. **专题合规性约束**：
   - Kids 专题：必须满足 `reviewStatus === "approved"`、`suitability.kids === "suitable"` 且包含明确儿童年龄段 (`4-6`, `7-9`, `10-12`)；
   - Friends 专题：必须满足 `reviewStatus === "approved"` 且包含 `relationships` 中的 `friends`；
   - Couples 专题：必须满足 `reviewStatus === "approved"` 且包含 `relationships` 中的 `couples`；
   - Funny 专题：必须满足 `reviewStatus === "approved"` 且包含 `tones` 中的 `funny`；
   - Hard 专题：必须满足 `reviewStatus === "approved"` 且包含 `difficulty === "hard"`。

## 5. 题库维护与导入方式

- **文件存储位置**：`src/modules/would-you-rather/data/questions.ts`
- **校验命令**：
  ```bash
  bun run test:unit -- tests/unit/would-you-rather/question-contract.test.ts
  ```
- **校验失败行为**：如果题库中存在重复 ID、无效标签、空题干、A/B 缺失或非法枚举，测试与构建将直接中断并报告具体错误题目 ID。
